# Handling Household Waste

A mobile application built with PhoneGap that helps users properly dispose of common household waste items and suggests environmentally friendly alternatives.

## Description

Handling Household Waste is a guide for environmentally responsible disposal of various household items. The app provides disposal methods for common household waste and suggests eco-friendly alternatives to reduce environmental impact.

## Features

- **Waste Disposal Guide**: Information on proper disposal methods for over 40 types of household waste
- **Eco-friendly Alternatives**: Suggestions for environmentally friendly alternatives to common household products
- **Local Resource Finder**: Locate nearby recycling facilities, junk yards, and hospitals using Google Maps
- **Works Offline**: Access disposal information without an internet connection (location services require connectivity)
- **Simple Interface**: Easy to navigate, user-friendly design

## Usage Instructions

1. From the main screen, select a household waste item from the dropdown menu
2. View recommended disposal methods and eco-friendly alternatives
3. Use the "Local Resources" button to find nearby facilities for proper disposal:
   - Select the type of facility you want to find
   - Enter your zip code or use GPS to find your location
   - View results on Google Maps

## Technology

- PhoneGap/Cordova mobile framework
- HTML5, CSS3, JavaScript
- Google Maps integration

## Installation

This application can be deployed to mobile devices using PhoneGap/Cordova:

1. Clone this repository
2. Use PhoneGap CLI or Adobe PhoneGap Build to compile the application
3. Deploy to your target device(s)
